{{ i('file') }} How to get a key (5 min, free)
  1. Open Google Cloud Console and create a project (e.g. “Hearth”).
  2. Enable the Google Calendar API for it.
  3. Go to IAM & Admin → Service Accounts → Create. No roles needed.
  4. Open the account → Keys → Add key → JSON. Upload that file here.
  5. In Google Calendar settings, pick a calendar (or create one called “Home”) → Share with specific people → add the service account email with Make changes to events.
  6. Copy the Calendar ID from Integrate calendar into the field here, then Test connection.
